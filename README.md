HR Analytics Dashboard | Power BI
An interactive Human Resources analytics dashboard built in Microsoft Power BI Desktop. The report is designed to explore employee attrition and workforce patterns across HR dimensions.
Project overview
This repository contains the Power BI report (HR ANALYTICS DASHBOARD.pbix) and supporting project documentation. The dashboard uses an HR_Analytics data model and includes KPI cards, categorical breakdowns, and a Department slicer.
Dashboard features
- KPI cards: employee ID count, average age, and attrition count (as configured in the report).
- Attrition breakdowns: visuals that analyze attrition by HR attributes such as gender and other workforce dimensions.
- Interactive filtering: a Department slicer is present.
- Power BI report canvas: a 1920 × 1080 report page titled “HR ANALYTICS DASHBOARD”.
Tools and skills demonstrated
- Microsoft Power BI Desktop
- HR / workforce analytics
- KPI cards and data visualization
- Interactive slicers and cross-filtering
- Data modeling and visual-level filtering

How to view the project
1. Download HR ANALYTICS DASHBOARD.pbix from this repository.
2. Open it in Microsoft Power BI Desktop.
3. If Power BI asks for data-source credentials or a missing source file, reconnect the original data source and select Refresh.
4. Explore the KPI cards, charts, and Department slicer.
